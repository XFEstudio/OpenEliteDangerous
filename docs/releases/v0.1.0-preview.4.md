# OpenEliteDangerous v0.1.0-preview.4 — SOLO recovery fixes

This release includes the location-loading and interrupted-launch permission fixes from [issue #1](https://github.com/XFEstudio/OpenEliteDangerous/issues/1).

- Native RPC 2 now accepts a location address containing a body index while checking that it belongs to the selected system. The previous adapter rejected a reproduced request near Earth in Sol, leaving subsequent reliable groups waiting and eventually disconnecting.
- The launcher recovers the exact read/execute grant left by an interrupted session of its private game profile. Normal exit removes that grant, including inherited access in descendants. Other explicit permissions are preserved.
- Existing preview.3 starter workspaces automatically receive the updated bundled business module. Their commander and save remain available. Manually published custom modules retain their selected version.
- Loader diagnostics include named stages, and RPC errors include method and payload shape information for troubleshooting.

Download **OpenEliteDangerous-v0.1.0-preview.4-solo-win-x64.zip**, verify it against **SHA256SUMS.txt**, extract the whole archive and run **Play-SOLO.cmd**. Save and exit before upgrading and back up your existing workspace. The default `%LOCALAPPDATA%\XFEEliteDangerous\SoloStarter` path is reused. For a custom path, run `Play-SOLO.cmd --workspace "<existing workspace>"`.

Requires Windows x64 and a lawfully obtained **Odyssey 2026.09.03.332841** installation. The game executable must match SHA-256 `e6be8bbe04e6a7ae226d4318945af7f367de13dc5a007a261964d9ba8144e988`. Steam discovery and manual selection are included.

The reported station drop and docking sequence still await a player replay. The [quick start](https://github.com/XFEstudio/OpenEliteDangerous/blob/v0.1.0-preview.4/docs/SOLO-QUICKSTART.md) explains the test sequence and current sandbox feature scope. This standalone ZIP provides basic flight and save/load. The management/server tools contain the ship, credit and equipment editing workbench.

The reporter in issue #1 shared Bitdefender's confirmation that the preview.3 `Atc4.Detection` alert was a false positive and that a signature correction was scheduled for November 16, 2026. Runtime validation of this new build with the reporter's updated Bitdefender installation is pending.

## 简体中文

本版发布 [Issue #1](https://github.com/XFEstudio/OpenEliteDangerous/issues/1) 的地点载入与异常退出权限恢复修复。

- 修复 RPC 2 拒绝含天体编号地点地址的问题，继续校验所属星系。此前已在太阳系地球附近复现拒绝、可靠消息等待与断线。
- 支持接管同一私有配置异常退出后遗留的准确读执行授权，正常退出时清除目录及子项中的对应授权，并保留其他权限。
- 旧 preview.3 工作区自动更新随包业务模块，保留指挥官与存档。手动发布的自定义模块保留已选版本。
- 补充加载器阶段、RPC 方法号和载荷格式日志，便于定位后续错误。

完整解压 **SOLO Windows x64** ZIP，双击 **Play-SOLO.cmd**。升级前保存退出并备份工作区。默认 SOLO 路径继续使用；自定义路径传入 `--workspace "<原工作区>"`。游戏版本和哈希要求见上文。

具体空间站的超巡退出和停靠仍待玩家复测。独立 ZIP 提供基础飞行与存档流程；改船、信用点和装备工作台属于管理端与服务器工具，功能范围见快速开始。

反馈者已转述 Bitdefender 确认 preview.3 告警为误报，并安排在 2026 年 11 月 16 日更新特征库。新版在其 Bitdefender 环境中的运行结果待反馈。仅供非商业教学研究。
