# OpenEliteDangerous v0.1.0-preview.3 — standalone SOLO

The SOLO launcher now checks Steam's main and added libraries for a compatible Odyssey installation. If it cannot find one, it opens a file picker for `EliteDangerous64.exe` and remembers a verified choice. There is no fixed drive letter. The launcher checks the build and takes you straight into SOLO.

Download **OpenEliteDangerous-v0.1.0-preview.3-solo-win-x64.zip**, verify it with **SHA256SUMS.txt**, extract everything and double-click **Play-SOLO.cmd**. The starter generates a private Sidewinder commander, a Sol practice spawn and local reference data, addressing the first-run setup reported in [issue #1](https://github.com/XFEstudio/OpenEliteDangerous/issues/1). It needs no server, login, imported save or extracted reference data. Existing starter saves are reused.

Requires Windows x64 and your own lawfully obtained **Odyssey 2026.09.03.332841** installation. The executable must match SHA-256 `e6be8bbe04e6a7ae226d4318945af7f367de13dc5a007a261964d9ba8144e988`. See the [SOLO quick start](https://github.com/XFEstudio/OpenEliteDangerous/blob/v0.1.0-preview.3/docs/SOLO-QUICKSTART.md).

This is a limited private flight sandbox. Full galaxy coverage, missions, Powerplay gameplay and multiplayer are outside its tested scope. **Educational and research use only; non-commercial use only.** Unofficial and unaffiliated with Frontier Developments. No official binaries, game assets, personal saves, private captures or service credentials are distributed. The executables are unsigned.
