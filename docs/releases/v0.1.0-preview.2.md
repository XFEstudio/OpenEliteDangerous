# OpenEliteDangerous v0.1.0-preview.2 — standalone SOLO

This preview addresses the first-run data gap reported in [issue #1](https://github.com/XFEstudio/OpenEliteDangerous/issues/1). The previous management/server package could run without having a native commander, while its native initializer needed a pre-existing spawn and system seed.

Download **OpenEliteDangerous-v0.1.0-preview.2-solo-win-x64.zip**, verify it with **SHA256SUMS.txt**, extract everything and double-click **Play-SOLO.cmd**. The launcher creates a private Sidewinder pilot, a Sol practice spawn and the reference documents locally. No server setup, account login, reference extraction, imported save, PowerShell or compiler is required.

The package requires Windows x64 and a lawful compatible **Odyssey 2026.09.03.332841** installation. This adapter still pins `E:\Elite Dangerous\Products\elite-dangerous-odyssey-64\EliteDangerous64.exe` and SHA-256 `e6be8bbe04e6a7ae226d4318945af7f367de13dc5a007a261964d9ba8144e988`. See the [SOLO quick start](https://github.com/XFEstudio/OpenEliteDangerous/blob/v0.1.0-preview.2/docs/SOLO-QUICKSTART.md).

The pinned client entered SOLO from a newly generated workspace and a fresh profile, moved 160.893 metres under the native flight test, saved, and reloaded the same position. All 790 managed regression tests passed. The starter is a limited private flight sandbox. Powerplay, missions, NPCs, colonisation, full galaxy coverage and multiplayer are outside the standalone package's verified scope. It leaves an existing management/server workspace alone.

This package does not distribute official binaries, asset packs, personal saves, private captures or service credentials. Third-party notices are included. The executables are unsigned.
