# OpenEliteDangerous v0.1.0-preview.1

First Windows x64 binary preview, including the WinUI management app, ServerInteractive server, bootstrapper, NativeAOT adapter and replaceable save/read business module.

- English and Simplified Chinese management UI and application messages.
- Shared private accounts, saves, factions and commodity/world definitions in one server.
- Live outfitting workbench: recorded engineering presets, custom relative parameters, experimental effects and removal of engineering.
- On-demand native loading of recorded module recipes, current magazine/reserve ammunition editing, and engineering/ammunition preservation through module storage and retrieval.
- Native acknowledgements, recovery and save reconciliation; offline and online save/re-entry checks.
- Binary initialization scripts, resolved dependency notices, optional debugging symbols and SHA-256 manifests. No compiler or .NET SDK is required to use the package; Windows x64 and PowerShell 7 are required.

## Download and setup

Download **OpenEliteDangerous-v0.1.0-preview.1-win-x64.zip**, verify it with **SHA256SUMS.txt**, extract everything, run **Initialize.cmd**, then **Start-Admin.cmd**. See the [binary setup guide](https://github.com/XFEstudio/OpenEliteDangerous/blob/v0.1.0-preview.1/docs/RELEASES.md).

The symbols ZIP is optional and follows the same directory structure. The JSON manifest records the source revision, supported image hash, validation scope and file hashes. GitHub's source-code archives contain source rather than the self-contained binary package.

## Validation and limits

788 regression checks passed again for this release on 2026-10-28. The included native runtime and save/read module retain the exact hashes of the 2026-10-22 acceptance build: 136 original-game checks covering live refits and offline/loopback-HTTPS saving/re-entry, plus 373 hidden bilingual UI checks. Packaging smoke checks exercise a clean extraction, initialization, server health, loader and hidden UI controls; they do not constitute a new full game or visual acceptance run.

This preview targets **Odyssey 2026.09.03.332841**, pinned to **E:\Elite Dangerous\Products\elite-dangerous-odyssey-64\EliteDangerous64.exe** and SHA-256 **e6be8bbe04e6a7ae226d4318945af7f367de13dc5a007a261964d9ba8144e988**. Other builds/paths require adapter changes and validation. A separately and lawfully obtained game installation, private native commander and reference data are required. Those inputs are not bundled. An empty install supports management setup and is not a ready-to-play game distribution.

Cross-computer/LAN/Internet use, reconnection, combat, NPCs, jumps and complete station transaction coverage remain unverified or incomplete. Recorded definitions are not a complete game database, and not every ship/blueprint combination has been tested. Executables are unsigned.
